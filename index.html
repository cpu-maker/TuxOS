TuxOS

Built with BLFS, for AR glasses

Origin/Spec Requirement

Build off of BLFS (Beyond Linux From Scratch) customized to work with 90% of lower tier miniature computers Pi using only 256mb of RAM.

Setup

First, make sure that your Pi can actually take the spec requirement. Then, go to the official source download at GitHub. (The ARM) Flash it onto your Pi, and then connect to your AR glasses.

GitHub repository for ARM download: href="https://github.com/cpu-maker/TuxOS/tree/main" Partnered with MEAT Glasses.
